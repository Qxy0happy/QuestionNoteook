# 拍摄路线：固定取景框 + 手选框 + 透视矫正，不做自动检测

预览界面只有一个固定居中的圆角矩形取景框（中心带十字准星）帮助对准。快门之后，用户在一个默认居中的矩形框上自己拖出可变边长的选区。选区确认后做一次透视重映射，把题拉正。

**明确不做自动题块检测。** 参照产品（夸克）的选区很可能是它自家 CV 检测出来的，但那意味着要训练并维护一个检测模型 —— 对一个自用工具不划算。用户原话：「自己搓 YOLO 太不划算，干脆默认中央吧」。

代价：选区是**轴对齐的矩形**，而轴对齐的矩形里没有透视畸变可矫正 —— 矩形裁出来还是矩形。所以今天这条路径上的透视重映射是一次**几何恒等变换**，拍歪的题会被**原样**带进成品。

（2026-09-16 更正：本节原文写的是「拍歪的照片里选区是轴对齐的，所以透视矫正不是可选项而是必需」。**那句话是错的** —— 轴对齐的矩形给不出题目的真实四角，矫正无从下手，把矩形喂给重映射只会得到恒等。采集侧的接口仍保留 quad 形状（而非收窄成矩形），是为了将来若改成四角可独立拖时，Go 侧一行都不用动；那是预留，不是当前能力。）
