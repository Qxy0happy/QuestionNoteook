# 04: 手选框 → 透视拉正 → 落盘

**What to build:** 快门之后底图铺满屏幕，上面压着一个居中的、**可变边长**的矩形选框，可以拖动。确认后应用把选区内那道题**透视拉正**，显示成卡片图，并把文件按**内容 hash** 落在沙箱里。

这是采集的核心：确认那一刻定稿，原图不再保留。

**Blocked by:** 03（取景与快门）

**Status:** ready-for-agent

- [ ] 选框初始居中、默认尺寸；拖角改尺寸、拖内部平移
- [ ] 确认后调用 Go 侧，传入原图与**四个角点**
- [ ] Go 返回拉正后的卡片图，界面上显示出来
- [ ] 卡片图按内容 hash 命名，落在应用私有目录
- [ ] 同一张图导入两次只产生一个文件
- [ ] 重拍与旋转可用
- [ ] 确认之后原图不再保留（这是刻意的，见 ADR-0007）
- [ ] Go 侧有 fixture 测试：喂一张**程序生成**的、带已知畸变的图，断言拉正后预期位置有预期像素
