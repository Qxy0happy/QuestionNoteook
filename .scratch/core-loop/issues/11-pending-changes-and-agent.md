# 11: 待批准层 + Agent 管理数据

**What to build:** 应用内有一个能读写数据的 agent。它**读得到一切**，但每一次写都先生成一条**待批准改动**，用户逐条批准或丢弃；批准前不影响正式数据。

**Blocked by:** 09（VLM 客户端）、10（讨论）

**Status:** ready-for-agent

- [ ] agent 能回答全局问题（如「我数学哪块最弱」），靠读数据
- [ ] agent 的每一次写都生成一条待批准记录
- [ ] 有一条测试断言**不存在绕过待批准层直接改数据的路径** —— 这是安全属性，不是功能
- [ ] 逐条批准、逐条丢弃都可用
- [ ] 丢弃一条不影响其他已批准的改动
- [ ] 界面上能看到待批准改动的清单与数量
