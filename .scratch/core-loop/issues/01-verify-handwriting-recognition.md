# 01: 先验手写识别

**What to build:** 用真实的、手写的考研错题照片喂一次云端 VLM，确认它到底能不能读出题干。这是一张**验证票** —— 产出是结论与证据，不是产品代码。它先做，因为它可能推翻后面的 VLM 相关票。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 取至少 3 张真实的**手写**错题照片（含公式，不含印刷体）调一次云端 VLM
- [ ] 记录：题干能否读出、公式识别到什么程度、失败时的具体形态
- [ ] 结论与原始输出落到 `.scratch/core-loop/` 下的一份文件里
- [ ] 若结论是「不可用」，明确给出替代方案（换模型 / 换输入方式 / 砍掉该功能），并说明影响哪几张票
