# 01: 用真实照片验一次打标签质量

**What to build:** 拿几道**真实的印刷体**错题照片走一遍打标签，看 VLM 给出的分层标签到底能不能用。这是一张**验证票** —— 产出是结论与证据，不是产品代码。

> 这张票原先写成「验手写识别」，**前提是错的**（2026-09-16 更正）：错题的**题目是印刷的**，用户拍的是习题册 / 真题上的印刷题面；手写只出现在用户自己的解答上，而那不进 VLM。所用模型的公开跑分本来就是印刷体文档问答 —— 那正是本场景，不是不利条件。
>
> 所以这里要验的**不是「能不能读」**，而是「给的分层标签合不合用、prompt 要怎么调」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 取至少 3 张真实的**印刷体**错题照片（含公式）走一次打标签
- [ ] 记录：标签层级对不对、粒度合不合适、prompt 需要怎么改
- [ ] 结论落到 `.scratch/core-loop/` 下的一份文件里，供票据 09 定 prompt 时参考
- [ ] 若标签质量不可用，明确给出替代方案（改 prompt / 换模型 / 退回纯手工打标签）
